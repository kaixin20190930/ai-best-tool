# Catalog 下一证据缺口（2026-10-21）

## 结论

在 Kling AI、Hailuo AI、Bubble、Avoma 四个未发布候选中，下一步优先补 **Kling AI 的真实产品媒体复用权**。本结论只指定一个缺口，不代表候选已 READY 或获准发布。

Kling 是 `product-image-to-short-video` Cluster 的 Anchor，能补齐视频生成决策组合；此前候选审计的身份风险已部分消解：当前官方 App 页面明确是图像/视频创作工作区，列出 Image Generation、Video Generation、Motion Control、Canvas 与 Avatar，并显示“Plans from $6.99”；官方文档另提供单独的 API 平台和资源包入口。因此必须维持实体边界：目录候选是 Kling AI 消费者/创作者 App，不是 Kling API，也不是单个 Kling 模型。[官方 App 页面](https://kling.ai/app/subscribe)；[官方 API 快速入门](https://kling.ai/document-api/guides/get-started/quick-start)

## 唯一待关闭缺口

现有候选审计指出官网可见素材不等于本站获得再使用许可；当前查到的官方页面没有给出可直接复用真实产品截图/输出的授权条款。故最优先动作是取得一项可留档的官方媒体许可/press asset 许可，覆盖用于 `/ai/kling-ai` 的实际 App 截图或演示输出。未确认前，不抓取或复制官网图像，不以模型宣传图冒充实测结果，也不因应用入口已清晰就解除媒体 HOLD。

来源：[Kling AI App](https://kling.ai/app/subscribe)；[Kling AI API Quick Start](https://kling.ai/document-api/guides/get-started/quick-start)。App 页面可确认产品身份和入口，但不是媒体许可证明。
